# Cztery pomysły na projekt GIS

Wybierz jeden temat i użyj pełnego promptu z tabeli ze skillem `write-prd` (`claude` -> `/write-prd`). Wynikiem jest `docs/PRD.md`, z pytaniami o zakres, mierzalnymi kryteriami i decyzją o MVP. [Skrypty i instrukcje pobierania realnych danych](../exercise-data/real/) działają przez uv na Windows i Linux. Wielkości wycinków zależą od obszaru i daty; wyniki rzeczywistych pobrań są w ich README.

| Pomysł i prompt | Publiczne źródła | Rozmiar MVP | Co ćwiczymy z agentami | Gdzie pasuje Jev by TypeSafe przez OpenRouter | Ryzyka |
|---|---|---|---|---|---|
| [Ładowarki EV i pokrycie dróg](PRD-ev-charging-map-conflation.md) | OSM/Overpass, Overture Places; drogi z OSM | Jeden bbox Łodzi, kilkadziesiąt ładowarek OSM; następnie województwo | Specyfikacja scalenia, SQL przestrzenny, testy progów, porównanie pól i review | Noul: to samo fizyczne miejsce; Choice: `public`, `customers_only`, `private`, `unknown`, bez podglądu `access` | Mało etykiet, różne definicje miejsca, nieaktualne tagi; odległość od drogi nie jest czasem dojazdu |
| [POI i kolejka weryfikacji](PRD-poi-conflation-review.md) | Overture Places i OSM/Overpass | Jedno miasto, tysiące miejsc; ogranicz obszar po policzeniu rekordów | Crosswalk kategorii, wykrywanie duplikatów, testy danych, mapa i decyzje człowieka | Choice nad stałą taksonomią, Noul duplikatu; kod kieruje niepewne wyniki do `human_review` | Zależność źródeł, trudne kategorie, fałszywe scalenia; zgodność źródeł to słabe etykiety |
| [Dostępność komunikacji](PRD-public-transport-accessibility.md) | Oficjalny GTFS Łodzi, granice jednostek UM, ludność UM/GUS BDL | Jeden feed, wybrana data; granice osiedli i zgodne statystyki | Rozpoznanie schematu, relacje SQL, czas ponad 24 h, bufory 400 m, weryfikacja agregatów | Opcjonalny Choice typu lokalizacji z nazwy/opisu przystanku; podstawą jest deterministyczny SQL | Kalendarze, powielone perony, niezgodne poziomy ludności, bufor nie mierzy drogi pieszej |
| [Jakość powietrza](PRD-air-quality-monitoring.md) | API GIOŚ v1: stacje, stanowiska, pomiary | Lista stacji w Polsce i kilka stacji pomiarowych w Łodzi | Import JSON-LD, paginacja, null, jednostki, testy detektora i wykresy | Opcjonalny Choice semantyki opisu stacji; anomalie liczbowe oblicza kod | Nieweryfikowane bieżące dane, brak odczytów, krótka historia, zmiana czasu |

Każdy wariant ma dashboard WWW z mapą MapLibre GL JS i OpenFreeMap bez klucza API, widoczną atrybucję OSM oraz pipeline Python + DuckDB. Wygląd bierze z tokenów w `assets/` utworzonych podczas kursu. Najmniej zależności od modelu ma transport lub powietrze; najwięcej ocen semantycznych do porównania z etykietami mają ładowarki i POI.

Nie potrzeba danych firmowych. Nie publikuj surowych pobrań bez sprawdzenia licencji; przykładowe downloadery przechowują je w ignorowanym `real/data/`. Klucz OpenRouter pozostaje na backendzie. Model jest opcjonalny tam, gdzie kod sam wystarcza; jego jakość mierzymy na oddzielnych etykietach zamiast zakładać poprawność odpowiedzi.
